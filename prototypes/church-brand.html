Church Brand Guidelines

로고 (Logo)

기본 로고

밝은 배경에서 사용하는 기본 로고입니다.
명확한 가독성을 위해 충분한 여백을 유지해주세요.

화이트 로고

어두운 배경에서 사용하는 화이트 로고입니다.
배경과의 대비를 고려하여 사용해주세요.

컬러 팔레트 (Color Palette)

사용 가이드 (Usage Guidelines)

✅ Do - 권장사항

  • 로고 주변에 충분한 여백 유지
  • 지정된 컬러 사용
  • 명확한 배경에서 사용
  • 비율 유지하여 확대/축소
  • 고해상도 이미지 사용

❌ Don't - 금지사항

  • 로고 색상 임의 변경 금지
  • 로고 비율 왜곡 금지
  • 로고에 효과 추가 금지
  • 복잡한 배경에 사용 금지
  • 저해상도 이미지 사용 금지
