# 성복교회 웹사이트 이미지 가이드

## 실제 교회 사진 사용 권장사항

현재 프로토타입은 Generic 이미지를 사용하고 있지만, 실제 배포 시에는 **성복교회의 실제 모습**을 담은 사진으로 교체하는 것을 강력히 권장합니다.

### 📸 우선순위 높은 이미지

#### 1. 히어로 슬라이더 이미지 (4개)
**현재 파일**: `images/main01.jpg`, `main02.jpg`, `main03.jpg`

**교체 권장**:
- **main01.jpg** → 예배당 전경 (주일 예배 전 모습)
- **main02.jpg** → 예배 중인 회중 모습 (하남교회 스타일)
- **main03.jpg** → 교회 건물 외관 또는 다음세대 모임
- **슬라이드 4** → YouTube 실시간 예배 영상 (유지)

**촬영 팁**:
- 밝은 자연광 활용
- 생동감 있는 예배 현장 포착
- 회중의 얼굴이 선명하게 보이도록
- 높은 해상도 (최소 1920x1080px)

#### 2. 다음세대 부서별 사진 (8개)
**현재 파일**: `images/dept_infant.jpg`, `dept_kindergarten.jpg`, 등

**교체 권장**:
- 각 부서의 실제 예배/활동 모습
- 아이들의 밝은 표정
- 교사와 함께하는 모습
- 부서별 특색 있는 활동 (찬양, 말씀 공부, 레크리에이션)

**개인정보 보호**:
- 아동/청소년 사진 사용 시 학부모 동의 필수
- 얼굴이 정면으로 나오지 않는 측면/뒷모습 활용 가능
- 단체 사진으로 개인 식별이 어렵게 촬영

#### 3. 교회 소식 이미지 (3개)
**현재 파일**: `images/news01.jpg`, `news02.jpg`, `news03.jpg`

**교체 권장**:
- **news01.jpg** → 부활절 연합예배 실제 사진
- **news02.jpg** → 청년부 수련회 단체 사진
- **news03.jpg** → 새가족 환영식 사진

#### 4. 교역자 사진 (16명)
**현재 파일**: `images/pro_c01.jpg` ~ `pro_c16.jpg`

**교체 권장**:
- 프로필 사진 스타일 통일
- 밝은 배경 + 정장/목회복
- 정면 상반신 샷
- 고화상도 (최소 800x1000px)

### 📝 촬영 체크리스트

#### 예배 현장 사진
- [ ] 주일 1부, 2부, 3부 예배 각각 촬영
- [ ] 찬양 시간 (손 들고 찬양하는 모습)
- [ ] 설교 중인 담임목사님
- [ ] 회중의 경건한 모습 (측면/뒷모습)
- [ ] 성찬식 또는 특별 행사

#### 다음세대 사진
- [ ] 각 부서별 예배 시간
- [ ] 교사와 학생들의 상호작용
- [ ] 찬양/율동 시간
- [ ] 말씀 나눔 시간
- [ ] 부서 특별 활동 (수련회, 야외예배 등)

#### 시설 및 공간
- [ ] 교회 건물 외관 (낮/저녁)
- [ ] 예배당 내부 (비어있을 때)
- [ ] 각 부서별 교실
- [ ] 주차장 및 안내 표지판
- [ ] 교회 주변 교통편 (지하철역, 버스정류장)

### 🔄 이미지 교체 방법

1. **파일명 유지**: 기존 파일명과 동일하게 유지
   ```
   기존: images/main01.jpg
   신규: images/main01.jpg (덮어쓰기)
   ```

2. **크기 최적화**:
   - 웹 최적화 도구 사용 (TinyPNG, ImageOptim 등)
   - 품질 80-90% 유지
   - 파일 크기 500KB 이하 권장

3. **백업**: 원본 고해상도 사진은 별도 보관
   ```
   prototypes/images/original/  (원본 보관)
   prototypes/images/           (웹 최적화 버전)
   ```

### 💡 참고: 다른 교회 사례

**하남교회 스타일 적용**:
- 예배 현장의 생동감 있는 모습
- 회중의 실제 표정과 몸짓
- 자연스러운 예배 분위기 포착

**다니엘기도회 스타일 적용**:
- 대형 이벤트 배너 이미지
- 강사/설교자 프로필 이미지
- 깔끔한 타이포그래피와 조화

### ⚠️ 주의사항

1. **저작권**: 모든 이미지는 성복교회가 직접 촬영하거나 사용 권한이 있는 것만 사용
2. **개인정보 보호**: 아동/청소년 사진 사용 시 학부모 동의서 필수
3. **품질 관리**: 흐릿하거나 구도가 안 좋은 사진은 사용 지양
4. **일관성**: 전체 웹사이트의 이미지 톤앤매너 일관성 유지
